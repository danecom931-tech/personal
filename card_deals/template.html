Set up one-tap refresh

The refresh button asks GitHub to run the search right away. It needs a GitHub key that can only start this workflow. You do this once per browser or phone.

  1. Open GitHub → New fine-grained token.
  2. Name it card deals refresh. Set an expiration (for example, 1 year).
  3. Under Repository access, choose Only select repositories and pick your repo.
  4. Under Permissions → Repository permissions, set Actions to Read and write. Leave everything else as is.
  5. Click Generate token, copy it, and paste it below.

Saved only in this browser. It can't read your code or change anything except start this workflow.
